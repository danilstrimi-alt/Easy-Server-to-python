## 📦 Установка

### Системные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- 500+ MB свободного места на диске

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/danilstrim3-spec/Easy-Server-to-python.git
cd Easy-Server-to-python
```

2. **Установите зависимости**
```bash
pip install -r requirements.txt
```

3. **Готово! Запустите программу**
```bash
python main.py
```

## 📚 Использование

### Главное меню

**Опция 1: Создать новый сервер**
- Выберите тип игры из списка
- Введите имя сервера
- Установите порт и количество игроков
- Сервер готов к запуску!

**Опция 2: Запустить сервер**
- Выберите сервер из списка
- Сервер запустится и будет готов к подключению

**Опция 3: Остановить сервер**
- Выберите запущенный сервер
- Сервер будет корректно остановлен

**Опция 4: Показать все серверы**
- Выведет список всех ваших серверов
- Покажет их статус и ресурсы

**Опция 5: Показать статус сервера**
- Выберите сервер
- Просмотрите детальную информацию (CPU, память, PID)

**Опция 6: Удалить сервер**
- Выберите сервер для удаления
- Сервер будет удален из системы

**Опция 7: Показать доступные игры**
- Просмотрите все поддерживаемые серверы
- Быстро запустите любой тип игры

## 🔧 Расширение функционала

### Добавление нового типа сервера

1. Откройте `main.py`
2. Найдите словарь `SERVER_PRESETS` в классе `ServerManager`
3. Добавьте новую предустановку:

```python
'my_game': {
    'type': 'my_game',
    'port': 9999,
    'max_players': 50,
    'start_command': './my_game_server --config=server.cfg',
    'description': 'My Custom Game Server'
}
```

4. Сохраните файл
5. Новая игра автоматически появится в меню!

## ❓ Часто задаваемые вопросы

### Q: Как изменить команду запуска сервера?
**A:** Отредактируйте JSON файл сервера в папке `servers/`:
```json
"start_command": "новая команда здесь"
```

### Q: Сервер не запускается. Что делать?
**A:** Проверьте:
1. Установлено ли необходимое ПО (Java для Minecraft, и т.д.)
2. Доступен ли указанный порт
3. Правильна ли команда запуска в JSON файле
4. Достаточно ли системных ресурсов

### Q: Можно ли запустить несколько серверов одного типа?
**A:** Да! Просто создайте несколько с разными названиями и портами.

### Q: Где хранятся конфигурации?
**A:** В папке `servers/` в виде JSON файлов. Вы можете редактировать их напрямую.

### Q: Как удалить все серверы?
**A:** Просто удалите папку `servers/` или используйте меню для удаления каждого отдельно.

### Q: Поддерживается ли Windows?
**A:** Да, полностью поддерживается!

### Q: Как узнать IP адрес сервера?

**Windows:**
```cmd
ipconfig
```

**Linux/macOS:**
```bash
ifconfig
# или
hostname -I
```

### Q: Экономит ли это ресурсы?
**A:** Да! Программа запускает только те серверы, которые вам нужны. Неиспользуемые серверы не потребляют ресурсы.

### Q: Могу ли я отредактировать конфигурацию вручную?
**A:** Да! Все конфигурации сохраняются в JSON файлах в папке `servers/`. Вы можете редактировать их любым текстовым редактором.

## 🐛 Решение проблем

### Python не найден
```bash
# Используйте python3 вместо python
python3 main.py
```

### Ошибка: "psutil не установлен"
```bash
pip install -r requirements.txt
```

### Ошибка: "Permission denied" (Linux/macOS)
```bash
chmod +x main.py
```

### Сервер не запускается
1. Проверьте логи в консоли
2. Убедитесь, что порт свободен
3. Проверьте, установлено ли необходимое ПО
4. Проверьте команду запуска в JSON конфигурации
