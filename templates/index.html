ℹ️ О приложении

Easy Server — это мощный инструмент для управления локальными игровыми серверами и приложениями на Windows, macOS и Linux.

✨ Основные возможности:

  • Предустановки для популярных игр
  • Мониторинг ресурсов (CPU, память)
  • Автоматическое сохранение конфигураций
  • Красивый веб-интерфейс
  • Поддержка Windows, macOS, Linux
